# Zeidgeist Prompter

A self-optimizing prompt enhancement system.

## Project Structure

- **backend/**: API server and prompt enhancement engine
- **frontend/**: Next.js web application
- **scripts/**: Utility scripts for development and deployment
- **deployment/**: Deployment configuration files
- **docs/**: Documentation files
- **archive/**: Archived older versions and unused code

## Getting Started

```bash
# Install dependencies for the monorepo
npm install

# Run both frontend and backend in development mode
npm run dev
```

## Development

- **Frontend only**: `npm run frontend:dev`
- **Backend only**: `npm run backend:dev`
- **Build for production**: `npm run build`
- **Start in production mode**: `npm start`

## Deployment

See the deployment documentation in the `deployment` directory for various deployment options.

## download and install

**quick install steps**:
1. download and extract the zip file
2. go to `chrome://extensions/` in chrome
3. enable "developer mode" (top-right toggle)
4. click "load unpacked" and select the extracted folder
5. pin the extension to your toolbar

## what it does

transforms your ai prompts from vague → specific and effective:
- works on chatgpt, claude, gemini, and other ai chats
- adds an "enhance" button next to text inputs
- keyboard shortcut: ctrl+shift+e (cmd+shift+e on mac)
- keeps history of enhanced prompts
- works offline with smart local rules
